## 2. Теоретическое обоснование

**CRUD** — набор четырёх основных операций над данными:

| Операция | Назначение | HTTP-метод |
|---|---|---|
| Create | Создание нового объекта | POST |
| Read | Получение одного или нескольких объектов | GET |
| Update | Изменение существующего объекта | PUT |
| Delete | Удаление объекта | DELETE |

**GET** используется для получения данных без их изменения. **POST** отправляет данные для создания объекта. **PUT** используется для полного обновления объекта. **DELETE** удаляет объект по указанному идентификатору.

Для обмена данными в работе используется формат JSON. В приложении Express функция `express.json()` позволяет серверу разбирать JSON из тела запроса и получать его через `req.body`.

Основные HTTP-коды состояния:

| Код | Название | Применение |
|---|---|---|
| 200 | OK | Успешное получение или обновление данных |
| 201 | Created | Успешное создание объекта |
| 204 | No Content | Успешное удаление без тела ответа |
| 400 | Bad Request | Некорректные входные данные |
| 404 | Not Found | Объект или маршрут не найден |
| 500 | Internal Server Error | Внутренняя ошибка сервера |

Данные в лабораторной работе хранятся в массиве в оперативной памяти сервера. Это упрощает разработку, так как не требуется база данных, но после перезапуска приложения изменения не сохраняются.

## 4. Контрольные вопрсы:

**1. В чём разница между PUT и PATCH?**  
PUT предназначен для полного обновления ресурса, а PATCH — для изменения только указанных полей. В данной работе используется PUT.

**2. Как реализовать поиск по коллекции (query-параметр `search`)?**  
Получить параметр через `req.query.search` и применить метод `filter()` к массиву. Для поиска по названию можно использовать `toLowerCase()` и `includes()`.

**3. Как реализовать сортировку по полю?**  
Использовать метод массива `sort()`: для числовых полей сравнивать разность значений, для строк — `localeCompare()`. Направление задаётся параметром `order=asc` или `order=desc`.

**4. Как реализовать пагинацию (постраничный вывод)?**  
Получить `page` и `limit`, вычислить начальный индекс `(page - 1) * limit`, затем извлечь часть массива методом `slice()`.

**5. Как валидировать входные данные?**  
Проверять наличие обязательных полей, их типы и допустимые значения. В работе `name`, `cuisine` и `address` должны быть непустыми строками, а `rating` — числом от 0 до 5.

**6. Какие коды ответов используются при ошибках валидации?**  
При неверных входных данных возвращается `400 Bad Request`; если запрошенный объект не существует — `404 Not Found`.

**7. Как вернуть `204 No Content` при DELETE?**  
В Express применяется `res.status(204).send()`. При этом тело ответа отсутствует.

**8. В чём разница между `res.json()` и `res.send()`?**  
`res.json()` отправляет JSON-ответ. `res.send()` может отправлять строки, объекты, буферы или пустой ответ в зависимости от переданного аргумента.

**9. Как избежать дублирования ID при создании новых элементов?**  
Использовать счётчик `nextId`, который увеличивается после добавления каждого ресторана.

**10. Что такое `express.json()` и почему без него `req.body` пустой?**  
`express.json()` — middleware для разбора JSON-тела HTTP-запроса. Без соответствующего обработчика сервер не сможет прочитать JSON как объект через `req.body`.
